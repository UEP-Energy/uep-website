# United Energy Professionals

The United Energy Professionals LLC website is built with React, TypeScript,
and Vite.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

Vite writes the production site to `dist`, ready to deploy to Cloudflare Pages.
Use `npm run preview` to check the production build locally.

## Contact and media

The contact form opens a prefilled draft in the visitor’s email app addressed
to `unitedenergypro@gmail.com`; it does not submit or store the message.

The Kyle O’ Watts introduction video is served from
`public/video/kyle-effigy-intro.mp4`. The player has native playback and sound
controls and does not autoplay. The original Design 1 logo image was not
included in this repository; add the approved logo before launching the
production site.
